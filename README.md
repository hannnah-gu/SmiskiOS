About: This website includes 2 working apps, and 4 windows that can be rearranged using a mouse. The images used were collected from pinterest. The goal of this project is to provide an OS that improves focus for students while studying. 

The timer app: A pomodoro timer app that allows students to track the time of their study periods

The quick notes app: Can be used for quick ideas, todo lists, class notes

To set up the website, it is only required to have an index.HTML, style.css, script.js and photo files. Paste the code and images into their respective files and doulbe press the index.html file to run the code.
